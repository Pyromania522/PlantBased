# PlantBased v0.1.0

The first PlantBased release provides local, calendar-based plant care for
Home Assistant **2025.10.0 or newer**, with full English/German UI support.

- Add plants and optional groups through Devices & services, without YAML,
  physical sensors, cloud accounts or external Python requirements.
- Independent watering/fertilizing schedules, seasonal fertilizing, date
  corrections, intervals, snooze, pause/vacation and bounded care history.
- Device/group actions, due/done events, an all-day calendar and due-care tasks.
- Opt-in grouped reminders with scoped Companion actions and persistent HA copies.
- Automatically loaded plant/group/overview dashboard cards, visual editors,
  theme/mobile support and twelve original SVG illustrations.

## Install or upgrade

In HACS, add `https://github.com/Pyromania522/PlantBased` as a custom repository
with category **Integration**, download this version and restart Home Assistant.
Add **PlantBased** under **Settings → Devices & services**. Refresh an open browser
tab before adding the cards; manual resource entries are unnecessary.

For manual installation, verify `SHA256SUMS`, then extract `plantbased.zip` into
your HA configuration's `custom_components/` directory. The archive contains
`plantbased/manifest.json` and the complete runtime, cards, illustrations and
license notices. The HA host does not need Node, npm or a frontend build.

Back up your HA configuration and `.storage` before upgrades. Keep the existing
hub when upgrading from the development milestones to retain its care history.
Removing the hub deletes its care/reminder stores. See README.md for uninstall,
restore, troubleshooting and linked automation examples.

## Validation and limits

The release workflow gates publication on hassfest, HACS, strict Python checks,
both minimum/current HA suites, browser/build checks and a verified release ZIP.
Exact executed counts and coverage are recorded in VALIDATION.md and GitHub CI.
The browser suite uses the real card bundle with a public-API fixture; HA's actual
HTTP/WS interfaces and lifecycle are tested separately. Full interactive HA and
phone delivery checks remain manual. Companion connectivity/provider limits apply.

HACS default-list submission, physical plant sensors, species databases and cloud
sync are outside v0.1.0. Code and original artwork are MIT licensed.

## Deutsch

Erste Version mit lokaler Pflanzenpflege, getrennten Gieß- und Düngeterminen,
Gruppen, Verlauf, Pausen/Urlaubsmodus, Kalender und Aufgabenliste. Optionale
Sammelerinnerungen unterstützen mobile Pflegeaktionen. Dashboard-Karten werden
automatisch geladen und enthalten zwölf eigene Pflanzenmotive.

In HACS als benutzerdefiniertes Repository der Kategorie **Integration** hinzufügen,
herunterladen und HA neu starten. Unter **Geräte & Dienste** PlantBased hinzufügen
und einen offenen Browser-Tab neu laden. Bei einem Update den bestehenden Hub
behalten; vorher die HA-Konfiguration einschließlich `.storage` sichern.
