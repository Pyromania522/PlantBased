# PlantBased v0.2.1

## Create plants and groups from the overview

- Administrators can use **Add plant** and **Add group** directly on the sidebar
  overview, including when no plants have been added yet.
- The dialog reads fields, defaults and translations from HA's existing native
  subentry flow. Optional groups, areas, illustrations, care intervals and initial
  care dates use the same backend validation and persistence as integration setup.
- Successful creation returns to the overview. Canceling/closing the page cleans
  up unfinished flows; pending submissions prevent duplicate requests.
- Non-administrators cannot use creation controls; HA enforces authorization.

## Upgrade

After publication, update through HACS, restart Home Assistant and refresh the
browser/app. Keep the existing hub and plants. Minimum HA remains **2025.10.0**;
no new runtime Python dependencies or storage migration are required.

## Deutsch

Auf der PlantBased-Übersicht gibt es jetzt direkt **Pflanze hinzufügen** und
**Gruppe hinzufügen** für Administratoren. Das Formular nutzt die Felder,
Standardwerte, Übersetzungen und Prüfungen des vorhandenen HA-Anlagedialogs.
Nach dem Anlegen erscheint die Pflanze/Gruppe in der Übersicht. Abbrechen entfernt
den unvollständigen Dialog ohne neue Pflanze oder Gruppe.

Nach Veröffentlichung über HACS aktualisieren, HA neu starten und Browser/App
neu laden. Vorhandene Pflanzen und Pflegeverläufe bleiben erhalten.
