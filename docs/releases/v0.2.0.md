# PlantBased v0.2.0

## Sidebar and plant overview

- PlantBased appears automatically in the Home Assistant sidebar after setup.
- The new page shows a card for every plant, including its photo/local illustration,
  live care status, watering/fertilizing countdowns and care actions.
- Switch between plants, group cards and plants organized by HA area. Empty groups
  and plants without a group or area are included.
- Search by plant, group or room and optionally show only plants needing care.
- Administrators can open integration settings and device/group details directly.
  Regular users can use the overview and existing authorized care actions.
- Existing Lovelace cards and HA's native integration settings remain available.

## Upgrade

After publication, update to v0.2.0 through HACS, restart Home Assistant and refresh
the browser. No new hub, dashboard YAML or manual frontend resource is required.
Existing plants, areas, groups and care history remain compatible. Minimum Home
Assistant stays 2025.10.0; there are no additional Python runtime requirements.

The new overview is available at `/plantbased-dashboard`. The sidebar follows HA's
normal per-user visibility preferences. The native integration page keeps HA's
standard layout; the PlantBased sidebar page provides the visual care overview.

## Deutsch

PlantBased erscheint automatisch links in der Seitenleiste. Die neue Übersicht

Düngeterminen sowie Pflegeaktionen. Du kannst zu Gruppenkarten oder einer

Nach Veröffentlichung in HACS auf v0.2.0 aktualisieren, Home Assistant neu starten
und den Browser neu laden. Vorhandene Pflanzen und Pflegeverläufe bleiben erhalten;
